# L4-006 — Authentication & Authorization

This module covers password hashing, JWT authentication, login, protected routes, role-based access control, and refresh tokens.

---

## Topics Covered

- Password Hashing with Argon2
- JWT Access Tokens
- PostgreSQL User Authentication
- Login System
- Protected Routes
- Role-Based Access Control (RBAC)
- Refresh Tokens

---

## Files

| File | Description |
|------|-------------|
| `l4_006_password_hashing.py` | Hash and verify passwords using Argon2. |
| `l4_006_jwt_tokens.py` | Create, sign, decode, and verify JWT access tokens. |
| `l4_006_create_users.py` | Create dummy users with hashed passwords and store them in PostgreSQL. |
| `l4_006_login_system.py` | Authenticate users from PostgreSQL and generate an access token. |
| `l4_006_protected_routes.py` | Protect FastAPI routes using Bearer JWT authentication. |
| `l4_006_role_based_access.py` | Restrict API routes based on user roles. |
| `l4_006_refresh_tokens.py` | Create refresh tokens and use them to generate new access tokens. |

# 1. Password Hashing

Run:

```bash
python3 l4_006_password_hashing.py
```

Expected:

```text
Password: Ahmed@1234
Hash: $argon2id$...

Correct password: True
Wrong password: False
```

### Flow

```text
Plain Password
      ↓
Argon2 Hash
      ↓
Password Hash

Login Password
      ↓
Verify Against Hash
      ↓
True / False
```

Run:

```bash

```

Test:

```text

Password: Ahmed@1234
```

Expected:

```text
Login successful.
Welcome: Ahmed
Role: admin
Access Token: eyJ...
```

### Login Flow

```text
Email + Password
       ↓
Search PostgreSQL
       ↓
User Found?
   ↓          ↓
  No         Yes
   ↓          ↓
 Reject    Get Stored Hash
                ↓
         Verify Password
                ↓
          Password Valid?
           ↓          ↓
          No         Yes
           ↓          ↓
        Reject     Create JWT
                       ↓
                Return Access Token
```

# 5. Protected Routes

Start FastAPI:

```bash
python3 -m uvicorn l4_006_protected_routes:app --reload
```

Open Swagger:

```text
http://127.0.0.1:8000/docs
```

Test:

```text
GET /public
```

No authentication is required.

Then authorize using the JWT generated by the login system and test:

```text
GET /profile
```

### Protected Route Flow

```text
HTTP Request
      ↓
Authorization: Bearer <JWT>
      ↓
Extract Token
      ↓
Verify JWT
      ↓
Valid?
 ↓          ↓
No         Yes
 ↓           ↓
401       Read Payload
             ↓
        Protected Route
             ↓
           200 OK
```

Stop the server before running the next FastAPI file.

# 6. Role-Based Access Control

Start:

```bash
python3 -m uvicorn l4_006_role_based_access:app --reload
```

Open:

```text
http://127.0.0.1:8000/docs
```

Test:

```text
GET /dashboard
GET /admin
```

An authenticated user can access:

```text
/dashboard
```

Only an admin can access:

```text
/admin
```

### RBAC Flow

```text
Request
   ↓
Verify JWT
   ↓
Authenticated?
   ↓
Check Role
   ↓
role == admin?
 ↓            ↓
Yes           No
 ↓             ↓
Allow       403 Forbidden
```

### Refresh Token Flow

```text
Login
  ↓
Access Token
Short Lifetime

+

Refresh Token
Longer Lifetime
  ↓
Access Token Expires
  ↓
Send Refresh Token
  ↓
Verify Refresh Token
  ↓
Check type == "refresh"
  ↓
Create New Access Token
```

# Important Rules

```text
Never store plain-text passwords.

Never commit real JWT secret keys.

Access Token
→ used to access APIs.

Refresh Token
→ used to obtain a new access token.

401 Unauthorized
→ authentication failed.

403 Forbidden
→ authenticated but not allowed.

PostgreSQL
→ stores users and password hashes.

JWT
→ proves authenticated identity on later requests.
```
